Special Notices & Amendments

Notices Amendment 3 has corrected the minor omission noted below. No other changes were made to the IVHM topics. An error was noticed in the text of the IVHM section. We intend to correct this in a future amendment that will be released soon, but a description of the correction is posted below. A portion of the third paragraph under the Description heading was inadvertently deleted. The correct paragraph is: The tradeoff between fidelity of the emulated data and anonymity of the data source is a key technical issue to be resolved in this effort. A critical risk that needs to be addressed is to minimize the probability of successful reverse engineering of the emulated data sets given that the data-mining capabilities need to be developed and validated using the emulator-generated data need to be validated before being applied to real data. Additionally, the emulator should generate realistic data that might be used in representations and analyses of future operational concepts of the air transportation system. Existing emulators should be leveraged where feasible, and sensitive aspects of the data (e.g., failures, exceedences and other safety concerns) may need to be added post hoc via simulation, if flights where such aspects were originally manifested can not be sufficiently disguised.
